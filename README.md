# kylebushwriting.com

Portfolio website for Kyle Bush, technical writer, instructional designer, and training coordinator.

The whole site is one self-contained `index.html` (styles, scripts, and logos are inline), served by GitHub Pages at https://kylebushwriting.com.

## Files

| File | Purpose |
|---|---|
| `index.html` | The site |
| `CNAME` | Custom domain for GitHub Pages |
| `robots.txt`, `sitemap.xml` | Search engine crawling |
| `.nojekyll` | Serve files as-is, no Jekyll build |

## Updating

Replace `index.html`, commit, and push to `main`. The live site updates within a minute or two.
